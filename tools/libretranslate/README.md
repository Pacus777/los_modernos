# LibreTranslate local para WAYNA

Este servicio permite traducir textos dinámicos del sistema sin usar APIs pagadas.

## Requisitos

- Python 3.10 o superior
- Conexión a internet solo para la primera instalación

## Instalación y ejecución en Windows

Desde la raíz del proyecto ejecutar:

```bash
tools\libretranslate\start-windows.bat
